# 초록 스튜디오 입력 브리프

> 이 파일을 프로젝트 루트에 `input-brief.md`로 복사해서 채운 뒤 "초록 스튜디오 돌려줘"라고 말하면 시작돼요.
> 모르는 칸은 비워 두세요. 비운 칸은 리서처가 조사로 채워요.

## 아이디어 (한두 문장)
예: 물 주는 걸 자주 잊는 자취생을 위한, 저면관수 방식의 이끼 화분. 모니터 옆에 둘 수 있을 만큼 작게.

## 키우고 싶은 식물 · 물 주는 방식
예: 비단이끼 · 저면관수 (정하지 않았으면 비워 두세요. 컨셉 디자이너가 자유롭게 제안해요)

## 지금까지 만든 것 (시제품 · 스케치)
- 상태: 예: 3D 프린팅 1차 시제품 있음 / 스케치만 있음
- 사진 경로: 예: `inputs/prototype-1.jpg` (없으면 비워 두세요)
- 아쉬운 점: 예: 물통이 너무 커서 책상에서 존재감이 큼

## 제약
- 크기: 바닥 면적 A5 (148×210mm) 이하
- 시제품 예산 (1개): 3만 원 이하
- 목표 판매가: 예: 3만 원 안팎 (레드팀이 가격을 판단하는 기준이에요)
- 소재: 예: 3D 프린팅 PLA 가능, 도자는 공방 의뢰 필요
- 꼭 지키고 싶은 것: 예: 흙이 보이지 않을 것

## 포트폴리오 용도
취업 / 지원사업 / 펀딩 / 판매 중에서 (포트폴리오 에디터가 구성을 맞춰요)

## 이번 실행에서 특히 보고 싶은 것
예: 3D 프린팅으로 바로 만들 수 있는 형태 위주로
