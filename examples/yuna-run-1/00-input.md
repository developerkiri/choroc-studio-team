# 초록 스튜디오 입력 브리프

## 아이디어 (한두 문장)
20대 후반~30대 초중반 1인가구 직장인을 위한, 책상 위에서 식물을 쉽게 키우면서 내 개성을 표현할 수 있는 식물 오브제

## 키우고 싶은 식물 · 물 주는 방식
이오난사, 일주일에 한번 물을 분무(촉촉해질 때까지)

## 지금까지 만든 것 (시제품 · 스케치)
- 상태: 3d 플라스틱 모델, 실제 금속(CR) 트레이(시제품)
- 사진 경로:
- 아쉬운 점:
  - 결합할 때 바닥 트레이와 벽면 트레이가 딱 맞지 않는 상황이 발생(금속 절곡률에 따라), 억지로 힘을 줘서 딱 맞게 하거나 나사를 세게 조이거나 함.
  - 시장에 너무 비슷한 제품이 많고 진입장벽도 낮음.
  - 단가가 너무 높은 것 같음(한 세트 - 바닥 트레이, 벽면 트레이, 디바이더(ㄴ자 철) 2종이 90,000원)

## 제약
- 크기:
  - 바닥 트레이 가로 26cm, 세로 21cm
  - 벽면 트레이 가로 26cm, 세로 16cm
- 시제품 예산 (1개): 90,000원
- 목표 판매가: 60,000원 대
- 소재:
  - 금속 전문 공장에, 철판을 구부려서 샘플 제작
  - 금형 만들어서 사출하는 방법은 단위가 너무 높아서 아직 시기상조
- 꼭 지키고 싶은 것: 이 제품은 다르다, 경쟁력이 있다, 차별성이 있다는 느낌이 있어야 함
