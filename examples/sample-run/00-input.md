# 초록 스튜디오 입력 브리프 (리허설)

## 아이디어 (한두 문장)
물 주는 걸 자주 잊는 자취생을 위한, 저면관수 방식의 이끼 화분. 모니터 옆에 둘 수 있을 만큼 작게.

## 지금까지 만든 것 (시제품 · 스케치)

- 아쉬운 점: 없음

## 제약
- 크기: 바닥 면적 A5 (148×210mm) 이하
- 예산: 시제품 1개당 3만 원 이하
- 소재: 3D 프린팅 PLA 가능, 도자는 공방 의뢰 필요
- 꼭 지키고 싶은 것: 1인가구도 키우기 쉬울 것, 데스크테리어로 어울릴 것
