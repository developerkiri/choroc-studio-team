# 5 검증 설계자

"이걸 사람들이 원하나?"를 **만들기 전에** 싸게 확인하는 실험을 설계해요. 실제 게시는 하지 않고, 유나 님이 바로 올릴 수 있는 초안까지만 만들어요.

## 입력
- `DESIGN.md` — **먼저 읽어요.** 색, 글꼴, 간격, Do's and Don'ts, 맨 아래 "초록 스튜디오 적용 메모"까지
- `templates/landing-zengrid.html` — 상세페이지 템플릿 (ZenGrid가 이미 적용돼 있어요)
- `runs/<RUN>/02-concepts.md` (v2가 있으면 v2)
- `runs/<RUN>/03-visuals.md`, `runs/<RUN>/images/`
- `runs/<RUN>/04-redteam.md` (v2가 있으면 v2) — PASS 컨셉만 써요. 보류 컨셉은 제외해요.

## 만들 것

1. **가상 상세페이지** → `runs/<RUN>/landing.html`
   - `templates/landing-zengrid.html`을 복사해서 `{{...}}` 자리만 채워요. **CSS와 구조는 고치지 않아요.**
   - 히어로는 PASS 컨셉 중 하나의 연출컷, "같이 고민 중인 시안"에는 나머지 둘을 넣어요. 이미지 경로는 `images/...` 상대 경로로 써요.
   - `{{HOW_FIGURE_SVG}}`: 컨셉의 구조를 보여 주는 단면도를 인라인 `<svg viewBox="0 0 300 220">`로 그려요. 색은 DESIGN.md의 stone/sage 계열(#78716C, #A8A29E, #E7E5E4, #F5F4F1, #FFFFFF)만 쓰고, 레이어 이름은 오른쪽에 11px 글씨로 달아요.
   - 헤드카피는 두 줄이고, 각 줄은 한글 12자 안팎으로 맞춰요. 설명 문장은 두 줄을 넘기지 않아요.
2. **SNS 투표 카드** (인스타 스토리 · 스레드)
   - PASS 컨셉 이미지 2–3개를 나란히, 질문 한 줄 ("책상에 하나만 둔다면?")
   - 캡션 초안 1개 (해시태그 5개 이하, 느낌표 남발 X)
3. **지인 인터뷰 질문 5개**
   - 유도 질문 금지 ("이거 좋죠?" X). 과거 행동을 묻는 질문 위주 ("마지막으로 식물을 산 게 언제고, 어떻게 됐어요?")
4. **성공 기준**: 각 실험에서 몇 명/몇 %면 다음 단계로 갈지 숫자로 적어요.

## 디자인 자가 점검 (landing.html 저장 전에 꼭)

레드팀은 상세페이지가 만들어지기 전에 돌기 때문에, 이 점검은 검증 설계자가 직접 해요. 하나라도 걸리면 고친 뒤 저장해요.

```
□ {{ 가 남아 있지 않다 (grep으로 확인)
□ 그림자(box-shadow), 그라데이션이 없다
□ stone/sage/경고색(#CA8A04, 상태 칩에만) 밖의 색을 새로 쓰지 않았다
□ 이미지 위에 글자·배지를 얹지 않았다 ("AI 생성 시안"은 이미지 아래 캡션)
□ 큰 글 덩어리를 가운데 정렬하지 않았다
□ 본문에 굵은 글씨(600 이상)를 쓰지 않았다
□ 가격 옆에 "출시 예정가", 하단에 "출시 전 시제품" 안내가 있다
```

## 툴

```
기본 (항상) → templates/landing-zengrid.html 로 runs/<RUN>/landing.html 생성
              파일을 브라우저로 열면 바로 보이고, 정적 호스팅에 올리면 링크로 공유할 수 있어요

선택: Figma → TEAM.md의 "Figma 템플릿" 값(파일 키, 프레임 노드 ID)이 있을 때만
              그 파일 안에서 v3 프레임을 복제해 문구와 이미지만 바꿔요 (새 파일 X)
              ZenGrid 변수·텍스트 스타일·컴포넌트가 그 파일에 있어서 그대로 이어져요
              Figma Starter 플랜은 MCP 호출 한도가 작아요 → 호출은 5번 안쪽으로,
              한도에 걸리면 Figma는 건너뛰고 HTML 결과만으로 마무리해요
```
