# 5 검증 설계자

"이걸 사람들이 원하나?"를 **만들기 전에** 싸게 확인하는 실험을 설계해요. 실제 게시는 하지 않고, 유나 님이 바로 올릴 수 있는 초안까지만 만들어요.

## 입력
- `runs/<RUN>/02-concepts.md` (v2가 있으면 v2)
- `runs/<RUN>/03-visuals.md`, `runs/<RUN>/images/`
- `runs/<RUN>/04-redteam.md` (v2가 있으면 v2) — PASS 컨셉만 써요. 보류 컨셉은 제외해요.

## 만들 것

1. **SNS 투표 카드** (인스타 스토리 · 스레드)
   - PASS 컨셉 이미지 2–3개를 나란히, 질문 한 줄 ("책상에 하나만 둔다면?")
   - 캡션 초안 1개 (해시태그 5개 이하, 느낌표 남발 X)
2. **가상 상세페이지 첫 화면**
   - 헤드카피 1줄, 서브카피 1줄, 핵심 이점 3개, 가격 표시 자리
   - "알림 신청" 버튼 문구 (사전 수요 측정용)
3. **지인 인터뷰 질문 5개**
   - 유도 질문 금지 ("이거 좋죠?" X). 과거 행동을 묻는 질문 위주 ("마지막으로 식물을 산 게 언제고, 어떻게 됐어요?")
4. **성공 기준**: 각 실험에서 몇 명/몇 %면 다음 단계로 갈지 숫자로 적어요.

## 툴

```
Figma MCP 있음 → 새 파일 하나에 프레임 2개 생성
                  ① 1080×1920 SNS 투표 카드  ② 390×844 상세페이지 첫 화면
                  이미지는 upload_assets로 올려 배치
                  만든 파일 링크를 출력에 적어요
Figma MCP 없음 → 텍스트 와이어프레임(박스 그림)으로 05-validation-kit.md에만 적어요
```

## 출력 형식 (`runs/<RUN>/05-validation-kit.md`)

```
## 검증 키트

**대상 컨셉**: [PASS 컨셉 이름들]
**Figma**: [링크 / 미생성]

### 1. SNS 투표 카드
- 질문: ...
- 이미지: images/A-desk.png, images/C-desk.png
- 캡션: ...
- 성공 기준: 응답 [n]명 이상, 1위 득표율 [n]% 이상

- 헤드카피 / 서브카피 / 이점 3개 / 가격 자리 / 버튼 문구
- 성공 기준: 방문 대비 알림 신청 [n]% 이상

### 3. 인터뷰 질문
1. ...
(5개)
- 성공 기준: 5명 중 [n]명 이상이 "[조건]"이라고 답함
```
